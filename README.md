# CAMPUSLINK

## Campus Link - DSA Based Student Networking System

Campus Link is a student networking and discovery system developed as a DSA project.

The current version focuses on implementing core Data Structures and Algorithms in C++ while providing useful student-oriented features such as student registration, login, searching, community management, connection requests, and activity tracking.

---

## Current Version

### Version 3.0

The current implementation contains:

- Student registration
- Student login with password
- Long Student ID support using `long long`
- Student profile storage
- Skill-based searching
- Branch-based searching
- Year-based searching
- Project-interest searching
- Display all students
- Community member management
- Connection request system
- Recent activity tracking
- Undo last activity
